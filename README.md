# 🤖 Aiogram Bot Template

Базовий шаблон для швидкого розгортання Telegram-ботів на `aiogram` з використанням менеджера пакетів `uv`.

## 🚀 Як створити нового бота

Цей репозиторій є шаблоном. **Не потрібно** створювати папку і робити `git init`. Робимо так:

1. Натисніть зелену кнопку **[Use this template]** -> **[Create a new repository]** вгорі сторінки на GitHub.
2. Дайте назву новому репозиторію та створіть його.
3. Склонуйте створений репозиторій собі на комп'ютер:
   ```
   git clone <ваше_посилання_на_новий_репо>
   ```
4. Перейдіть у папку з проєктом:
   ```
   cd <назва_папки>
   ```
5. Встановіть усі залежності та створіть віртуальне середовище .venv однією командою (переконайтеся, що у вас встановлено uv):
   ```
   uv sync
   ```
